# AGENTS.md — DSH OpenAI Subscription

This is an independent, optional DSH plugin repository, not a DSH workspace package. Read [the implementation plan](docs/IMPLEMENTATION_PLAN.md) before changing behavior; verify APIs against the DSH version actually targeted. The [copied development skills](.agents/README.md) cover UI judgment, asynchronous tests, and browser recordings. Upstream DSH rules and scripts are references, not commands available in this repository.

- Ship one opt-in Bundle with Host and Client entries. Do not change DSH's official settings page, `llm-pi-ai`, Desktop native code, or another plugin's routes and credential records. Only supported `dsh` profiles launch the application.
- Follow the Cordis Loader form for the chosen entry: function plugins named-export `name`, `inject`, `Config` when present, and `apply`, with no default export; services use the documented service-class form. Declare required injections; read truly optional services through `ctx.get(name)`. Register slots, adapters, remotes, and listeners as effects and verify disposal.
- Give this plugin its own provider route and credential key. Keep OAuth state, tokens, refresh, callback handling, and quota requests on Host; never send secrets to the browser, logs, Session, screenshots, or demo artifacts. A remote-browser fallback needs an actual verified flow, not an assumed device grant.
- `LlmAdapter` request token usage is not subscription quota. Display only server-provided limits/windows/reset times; absent values are unknown, not zero. Quota failure must not invalidate a working model login. Never consume a reset card without a separate explicit confirmation and server-side result.
- Treat login, refresh, cancellation, sign-out, and unload as owned asynchronous lifecycles: avoid duplicate attempts, contain callback failures, release ports/listeners/requests, and publish state only after successful writes. Validate external provider responses and Remote/wire inputs; do not add redundant runtime checks for statically typed local calls.
- Client content goes through typed locale dictionaries; components use the declared `settings.section` slot and existing primitives/tokens. Keep Host business data off the browser. Test light/dark themes, narrow layouts, keyboard dismissal, and Desktop window chrome.
- Keep README and API JSDoc aligned with implementation. Run focused unit tests, a real Loader/profile composition test, a built-package smoke test, and real-API authorization/model/quota checks when an authorized test account is available; report unrun or skipped checks honestly. Do not claim real login from mocks. GUI PRs should demonstrate their real flow with a privacy-reviewed recording.
- Before committing, inspect `git diff --check` and run the checks this repository actually defines. Do not invoke DSH-monorepo `pnpm` scripts here unless working in a separate DSH checkout to test compatibility. Never commit credentials or real OAuth responses.

Recheck their current versions for a newer target DSH release.
