# 订阅限额：实现与验证

设置 → OpenAI 在登录后显示五小时与每周额度，位于默认收起的模型列表上方。页面首次挂载查询，Host 缓存成功结果 60 秒；手动刷新绕过缓存，但与已经进行中的查询合并。页面只更新倒计时，不后台轮询。

Host 使用本插件的 OAuth 请求 `https://chatgpt.com/backend-api/wham/usage`。2026-10-03 经用户明确授权，真实响应确认了 `rate_limit.primary_window` / `secondary_window` 中的 `used_percent`、`limit_window_seconds` 和 `reset_at`。按持续时间识别 300 / 10080 分钟窗口，剩余比例为服务端已用比例的补数。窗口或重置时间缺失显示未知；倒计时到期时等待服务端更新，不自行清零已用比例。

这是未作为稳定公开 HTTP API 文档化的接口。请求限时 15 秒、响应限制 64 KiB，禁止重定向；Host 仅返回窗口与查询时间，丢弃账户身份、套餐、credits 等其他字段。认证或额度请求的诊断不会进入 Client。退出登录及卸载取消请求、等待释放租约、清除缓存，旧响应不能进入后续账户生命周期。额度失败不改变模型登录态，重置卡消费不在本次范围。

## 已完成验证

- 实际生产额度模块使用已授权 OAuth 查询成功；未用模拟响应替代真实 API 验收。
- 独立 DSH Web profile 使用正常凭据服务，真实 Host Loader、Typert Remote 和浏览器 Client 组合显示两个额度窗口；手动刷新后更新时间改变。
- 独立浏览器断网后刷新，实际显示失败提示并保留上次额度；恢复网络重试后提示消失，仍保持登录。
- 深浅色和窄窗口检查未发现额度区域横向溢出。模型列表默认收起，点击可展开八个真实发现的模型；原生 summary 可获得焦点。浏览器桥接未能可靠验证原生键盘激活，不能据此声明该项通过。
- `pnpm typecheck`、143 项单元测试、`pnpm test:package`、`npm pack --dry-run` 与 `git diff --check` 通过。单元测试覆盖解析边界、缓存合并/过期/失败、账户生命周期隔离和登出等待额度租约。
- 打包产物在独立 profile 的实际 DSH Loader 中装载、独立组件启停及卸载检查通过。此项使用合成认证和服务替身验证资源生命周期，与上述真实 Web/API 验证分开。
